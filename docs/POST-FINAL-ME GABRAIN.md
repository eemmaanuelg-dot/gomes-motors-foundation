# GATE PÓS-FINALIZAÇÃO — MEGABRAIN

## Regra registrada em 13/09/2026

Quando o Gomes Motors estiver **100% finalizado, funcional, validado e aprovado na fase de fundação**, antes de iniciar qualquer transformação visual premium, lembrar o usuário de executar a fase **MegaBrain** no projeto.

### Objetivo da fase MegaBrain

O MegaBrain não deve substituir ou descaracterizar o Gomes Motors existente. A finalidade é **refinar e elevar a experiência do projeto já consolidado**, preservando a estrutura, funcionalidades, dados e identidade comercial existentes sempre que possível.

### Princípio obrigatório

> Evoluir o Gomes Motors existente; não criar um novo site desconectado da aplicação.

### Diretrizes para a futura transformação

- Preservar funcionalidades, rotas, dados, estoque e fluxos já validados.
- Usar veículos reais do próprio estoque na experiência visual, inclusive em possíveis cenas 3D do hero.
- Não inserir veículos fictícios ou "do futuro" apenas para efeito visual quando isso não fizer sentido para a concessionária.
- Reutilizar dados reais do catálogo sempre que uma experiência visual puder ser vinculada dinamicamente ao sistema.
- Refinar componentes existentes em vez de substituí-los sem necessidade.
- Introduzir progressivamente 3D, animações, iluminação, partículas, objetos em movimento, scroll cinematográfico, transições, vídeos, interfaces detalhadas e componentes interativos.
- Manter responsividade e experiência mobile como requisitos de primeira classe.
- Tratar performance como requisito obrigatório, especialmente para WebGL/3D/vídeo.
- Validar cada grande camada adicionada e corrigir problemas antes de avançar.
